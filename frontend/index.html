DropAPI

Drop a CSV into S3. A Step Functions workflow checks it, loads it, and gives you a live API and a plain-English question box. No servers, no pipeline.

To add a dataset, run: 
aws s3 cp mydata.csv s3://dropapi-uploadbucket-om7mtkx1okwn/uploads/mydata.csv
The status below updates by itself. Use letters, numbers, - or _ in the file name.
